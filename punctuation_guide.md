# **Punctuation Marks in HTML and XML (a short guide)**
## **Tag Marks**
### *Angle Brackets (< and >)*
Used to open and close tags.
### *Forward Slash (/)*
Used to close an element.\
Examples:
``` json
{
  <tag>Content<tag/>
  <self-closing-tag/>
}
```
